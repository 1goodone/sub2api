# Third-party notices

This plugin implements a rustls ClientHello captured from official
`codex-cli` 0.146.0 and sends it with `github.com/refraction-networking/utls`.
HTTP/2 uses `golang.org/x/net/http2`. Proxy CONNECT/SOCKS5 handling follows
the same patterns as Sub2API's CPA-compatible transport plugin.

This plugin is not an official OpenAI or Codex CLI release.
