# Third-party notices

This plugin implements a ClientHello captured from official
Codex Desktop's bundled `codex.exe` (`codex-cli` 0.153.4, app 26.903.9818.0;
Windows Schannel TLS 1.2) and sends it with `github.com/refraction-networking/utls`.
HTTP/2 uses `golang.org/x/net/http2`. Proxy CONNECT/SOCKS5 handling follows
the same patterns as Sub2API's CPA-compatible transport plugin.

This plugin is not an official OpenAI or Codex Desktop release.
