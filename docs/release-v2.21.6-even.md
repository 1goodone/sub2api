# Sub2API v2.21.6 (Even)

本版汇总此前 v2.21.1 至 v2.21.5 的本地集成，并整合上游 v2.21.6、Issue #892 / PR #895 的时区与历史恢复修复，以及本地限流、代理和 TOTP 并发修复。保留本仓库的缓存减免、分组/个人倍率、账号偏好和 worker 部署方式。

## 主要修复

- 修复 #892：从不可变原始输入生成所选账号的有限时区投影，HTTP/WS 续接不再因合法的账号时区替换被完整性校验误拒绝；任务、密文、工具参数/结果和历史归属仍严格校验。
- 账号额度耗尽时继续换号，全池不可用最终返回 503；用户自身限流与普通瞬时限流仍使用 429。首条 SSE quota 拒绝可进入换号，嵌套 `response.error` 正确保留分类与 reset，不再对明确额度耗尽的同一账号长时间重试。
- 请求代理池不可用时进入原有账号 failover，由 handler 写入一次最终响应；不绕过指定出口、不提前写 503 或追加错误 SSE。
- TOTP 轮换对规范化邮箱使用事务级互斥，阻止不同账号记录对同一身份同时创建轮换；保留软删除再导入保护。
- 整合上游按请求多代理、HTTP/WS 历史恢复、模型目录、Gemini 结构化输出、默认关闭的 UltraFast 免费分组选项，以及 TOTP factor 绑定与 journal 协议。目录声明不等于真实供应商能力验收。

## 升级与回退

- 本仓库新增迁移为 `389_group_free_openai_ultrafast.sql`、`390_openai_totp_binding.sql`；既有迁移编号及本地字段保留。
- server 和 worker 必须成套升级，保留数据库、配置、加密密钥及 worker 恢复 journal。已写入新 TOTP 格式后不能直接回退旧 server/worker。
- 免费 UltraFast 默认关闭。启用后回退前须先处理相关计费设置；多代理配置也须遵守有效出口与统一升级约束。
- Server 40 Main/MR 已于 2026-11-17 蓝绿升级至本版应用代码，两个 worker 成套升级并重绑，并发分别为 3/2；旧实例连接排空后正常停止，保留容器、镜像和备份。
